What does an email verification API do?

An email verification API tells your app whether an address can receive mail. Your backend sends the address over HTTPS. The API returns one status and the reason behind it. Your code then accepts, flags or rejects the address.

Run it at sign-up to stop fake accounts. Run it at checkout to catch typos. Run it on a list before a campaign to protect your sender reputation, because email lists decay by about 22.5% a year. The BillionVerify email verification API handles one address or a full file.

What does each email status mean?

Each result carries a single status, so your code stays simple. Read the status reference and the verification reasons for the full list.

StatusMeaningCost
valid The mailbox accepts mail. 1 credit
invalid The address cannot receive mail. 1 credit
catchall The domain accepts every address, so one mailbox cannot be confirmed. 1 credit
role A shared inbox such as info@ or support@. 1 credit
disposable A temporary inbox from a known provider. Free unless check_smtp is true
unknown The mail server gave no definite answer. Free

How do you block temporary email at sign-up?

Email verification API FAQs

What is an email verification API?

An email verification API is a web service that tells your app whether an address can receive mail. You send one address or a list. The API returns a status for each address, and your code decides what to do next.

Does email verification send an email?

Email verification does not send a message. The check asks the receiving mail server about the mailbox and stops before any message is sent.

What does an unknown result mean?

An unknown result means the mail server gave no definite answer. Unknown results cost nothing, and a re-check within 24 hours is free.

Is a catch-all address counted as valid?

Catch-all is reported as its own status. A catch-all domain accepts every address, so nobody can confirm one mailbox on it.

Which languages have an SDK?

SDKs cover Node.js, TypeScript, Python, Go, PHP and Java. They are open-source reference implementations on GitHub. The REST API is the source of truth, and any language can call it over HTTPS.

Can the API block temporary email at sign-up?

The API flags disposable addresses in its result, so your form can refuse them or tag them as low trust. A separate disposable check endpoint is free and does not use credits.
