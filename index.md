# BillionVerify - Email Verification API & SDKs

Canonical page: https://billionverify.github.io/

Validate email addresses in real-time or clean millions of records with the BillionVerify API, SDK docs, guides and market benchmark.

## API example

```bash
curl -X POST \
  https://api.billionverify.com/v1/verify/single \
  -H "BV-API-KEY: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"email": "test@example.com"}'
```
