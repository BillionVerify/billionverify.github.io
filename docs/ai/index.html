Quick Start

Option 1: Remote MCP for ChatGPT and Claude Users (Recommended)

If your client supports remote MCP over HTTP, use the hosted BillionVerify endpoint:

https://mcp.billionverify.com/mcp

For Claude Code, run:

claude mcp add --transport http billionverify https://mcp.billionverify.com/mcp

Then run /mcp inside Claude Code and complete OAuth in your browser.

The hosted server uses OAuth and does not accept API keys. If your client only supports local stdio servers with API keys, run the self-hosted billionverify-mcp npm package (it reads BILLIONVERIFY_API_KEY), or use the BillionVerify CLI or REST API. See MCP Server.

Option 2: AI SDK Tool for Developers

Building a custom AI application? Add email verification as a tool:

import { tool } from 'ai';
import { z } from 'zod';

const verifyEmailTool = tool({
  description: 'Verify if an email address is valid and deliverable',
  inputSchema: z.object({
    email: z.string().email(),
  }),
  execute: async ({ email }) => {
    const response = await fetch(
      'https://api.billionverify.com/v1/verify/single',
      {
        method: 'POST',
        headers: {
          'BV-API-KEY': process.env.BV_API_KEY!,
          'Content-Type': 'application/json',
        },
        body: JSON.stringify({ email }),
      },
    );
    const { data } = await response.json(); // the API wraps results in { success, code, message, data }
    return data;
  },
});

Option 3: CLI for Terminal Users

# Install
npm install -g billionverify

# Configure
billionverify config set api_key YOUR_API_KEY

# Verify
billionverify verify john@example.com

# JSON output for AI parsing
billionverify verify john@example.com --json

API Quick Reference

For AI integration, use these API endpoints:

Single Verification

curl -X POST https://api.billionverify.com/v1/verify/single \
  -H "BV-API-KEY: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"email": "test@example.com"}'

Response (abridged; the result is in data):

{
  "success": true,
  "code": "0",
  "message": "Success",
  "data": {
    "email": "test@example.com",
    "status": "valid",
    "score": 0.95,
    "is_deliverable": true,
    "is_disposable": false,
    "is_catchall": false,
    "is_role": false,
    "is_free": false,
    "domain": "example.com",
    "credits_used": 1
  }
}

Key Response Fields

These fields are inside data.

FieldDescriptionAI Interpretation
statusvalid, invalid, unknown, risky, disposable, catchall, rolePrimary decision field
is_deliverableCan receive emailSafe to send?
is_disposableTemporary emailBlock registration?
is_catchallThe domain accepts mail for any addressCannot confirm the mailbox
is_roleinfo@, support@, etc.Shared mailbox warning
scoreA number from 0 to 1Risk assessment
